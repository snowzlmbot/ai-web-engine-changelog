# AI Web Engine v1.3.0

Public assets are AES-256-GCM authenticated, chunk-encrypted self-decrypting ELF executables. The repository does not contain source code, plaintext engine binaries, plaintext shell scripts, raw APK files, release keys, signing private keys, or project state.

Each ABI has an independent Ed25519 script manifest. Verify all published bytes with SHA256SUMS before execution.
