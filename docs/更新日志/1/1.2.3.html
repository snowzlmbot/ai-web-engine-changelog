## 版本主题

## 变更详情

- 修复启动前不生成本机 skills 索引的问题。
- 引擎启动构造阶段会扫描 `/data/local/ai-instruction/This machine skills`，并原子生成 `skills-index.json`。
- 索引仅包含名称、相对路径、来源、类型、摘要和大小，不包含 skill 正文。
- 可选目录不存在时不创建目录且不阻止引擎启动；空目录会生成空索引。
- 新增启动级回归测试，验证首次启动、空目录和新增 skill 后的索引更新。
